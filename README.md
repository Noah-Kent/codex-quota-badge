# Codex Quota Badge

一个轻量、安全、本地优先的 macOS 菜单栏工具，用来查看 Codex 的 5 小时与 7 天剩余配额。

**无网络请求 · 不读取凭据 · 日志只读 · 无遥测**

```text
5H 52%
7D 92%
```

![Codex Quota Badge 详情窗口](assets/screenshots/detail-preview.png)

频繁打开用量页面会打断工作。Codex Quota Badge 只把最重要的配额信息放到菜单栏，并在点击后显示重置时间和最后更新时间。

> 当前为开发预览版。仓库暂时提供源码运行方式，签名并经过 Apple 公证的安装包将在首个正式版本提供。

## 运行与安装

### 从源码运行

要求：

- macOS 13 或更高版本；
- Swift 6 命令行工具；
- 至少运行过一次包含配额信息的本地 Codex 会话。

克隆仓库并进入项目目录后执行：

```bash
bash scripts/run-local.sh
```

工具不会出现在 Dock 中，而是显示在 macOS 菜单栏。点击配额区域可以打开详情；点击“完全退出”即可结束程序。

也可以手动构建：

```bash
swift build
swift run CodexQuotaBadge
```

### 开发预览安装包

本地可生成 `.app` 和 `.dmg` 预览包：

```bash
bash scripts/create-preview-dmg.sh
```

产物位于 `dist/`。它使用临时签名，仅用于本机预览，**尚未经过 Apple 公证**。Gatekeeper 会将它标记为不受信任，因此不要把该预览包分发给其他用户。正式可公开下载的版本会使用 Developer ID 签名并完成 Apple 公证。

## 主要功能

- 菜单栏双行紧凑显示 5 小时和 7 天剩余配额；
- 点击后查看两个周期的重置时间与最后更新时间；
- 提供“立即刷新”“隐藏详情”和“完全退出”；
- 无标题栏详情窗口，可从按钮以外的区域拖动；
- 没有可用日志时显示“未检测到配额”，不会崩溃；
- 日志暂时不可读或末行不完整时保留最近一次有效快照；
- 完全离线工作，不依赖 OpenAI API 或第三方服务器。

## 安全与隐私

| 行为 | 本工具是否执行 |
| --- | --- |
| 读取本地 Codex 会话日志 | 是，仅用于定位配额字段 |
| 保存或上传会话正文 | 否 |
| 修改或删除 Codex 文件 | 否 |
| 读取浏览器 Cookie | 否 |
| 读取账号密码、Token 或 API Key | 否 |
| 向 OpenAI 或第三方发送请求 | 否 |
| 上传使用记录或遥测数据 | 否 |
| 保存配额历史数据库 | 否 |
| 自动操作用户账号 | 否 |

工具会在本机打开 Codex 会话日志文件，以定位其中的配额快照字段，例如 `payload.rate_limits`。解析过程中不会把日志正文保存到其他位置、上传或发送给其他程序。所有处理都在当前 Mac 上完成，退出后内存中的快照随进程释放。

这里所说的“安全”是指最小权限、本地只读、无网络传输和不干预 Codex。任何软件都不应承诺绝对零风险；如果你对本地日志访问仍有顾虑，可以先审查源码再运行。

## 为什么它很轻量

首次启动时，工具会在 `~/.codex/sessions` 中定位最近的有效配额日志，并只在内存中保存：

- 当前日志路径；
- 文件修改时间；
- 最近一次有效配额快照。

后续每分钟刷新时：

1. 当前日志没有变化：直接复用内存快照，不重新读取或解析；
2. 当前日志发生变化：只重新解析这一份文件；
3. 出现新会话、日志被删除或目录结构变化：重新定位有效日志。

目录变化由 macOS 文件系统事件通知，只用于标记“需要重新定位”，不会持续轮询目录，也不会在事件发生时反复扫描。

```text
本地 Codex 日志
       ↓ 首次定位
缓存路径、修改时间和配额快照
       ↓ 每分钟检查状态
 ├─ 未变化 → 复用内存快照
 ├─ 文件变化 → 只解析当前文件
 └─ 会话变化 → 重新定位日志
       ↓
菜单栏显示 5H / 7D 剩余配额
```

## 常见问题

### 为什么显示“未检测到配额”？

可能尚未产生包含配额信息的本地 Codex 会话。工具不会要求登录，也不会转而读取浏览器或账号凭据。

### 必须一直打开 ChatGPT 或 Codex 吗？

不需要。关闭后工具可以继续显示最近一次有效快照；只有 Codex 写入新的本地配额数据后，数值才会更新。

### 为什么和网页上的数值不完全一致？

工具读取的是最近一次写入本地日志的快照，而不是官方公开 API，因此可能暂时落后于网页端。

### Codex 更新后无法识别日志怎么办？

本地日志格式属于实现细节，未来可能发生变化。请提交 Issue，并只提供最小化、脱敏后的样本，不要上传完整会话日志。

### 如何退出或卸载？

点击详情窗口中的“完全退出”。当前源码版本不会安装登录项、后台服务或配额历史数据库；删除克隆的项目目录即可移除源码和构建文件。

### 为什么菜单栏没有显示？

先确认程序仍在运行。菜单栏空间拥挤时，macOS 或第三方菜单栏管理工具也可能隐藏项目。

## 当前限制

- 目前只针对 macOS，并以源码形式运行；
- 配额来自 Codex 本地日志，日志格式变化时可能需要更新解析器；
- 不包含登录、账号切换、购买额度、通知或自动更新；
- Apple Silicon 已在当前开发设备上验证；Intel Mac 尚未验证；
- 当前尚未完成正式 Release 构建的 CPU、内存和磁盘实测，README 不预先填写估算数据。
